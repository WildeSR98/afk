## 🔧 Требования

- **Windows 10/11**
- **AutoHotkey v2.0** или выше
- Установленный и запущенный **Roblox Player**

## 📥 Установка

1. **Установите AutoHotkey v2**, если ещё не установлен:
   - Скачайте с официального сайта: https://www.autohotkey.com/
   - Выберите версию **v2.x**

2. **Склонируйте или скачайте репозиторий**:
   ```bash
   git clone <repository-url>
   cd RobloxAFKKeeper
   ```

3. **Убедитесь, что все файлы на месте**:
   - `RobloxAFKKeeper.ahk` — главный файл запуска
   - Папки: `lib/`, `lang/`, `resources/`, `vendor/`, `tools/`

## 🔑 Активация

При первом запуске приложение потребует активации.

### Шаг 1: Запуск

Запустите главный файл:
```bash
AutoHotkey.exe RobloxAFKKeeper.ahk
```
Или дважды кликните по файлу `RobloxAFKKeeper.ahk`.

### Шаг 2: Ввод кода активации

Откроется окно активации:

```
┌─────────────────────────────────┐
│         АКТИВАЦИЯ               │
├─────────────────────────────────┤
│  Введите код активации          │
│  (16 символов)                  │
│                                 │
│  Формат: XXXX-XXXX-XXXX-XXXX    │
│                                 │
│  [_________________________]    │
│                                 │
│     [АКТИВИРОВАТЬ]              │
│         [EN/RU]                 │
└─────────────────────────────────┘
```

### Шаг 3: Валидация кода

- Код должен содержать **ровно 16 символов** (латинские буквы и цифры)
- Формат ввода: `XXXX-XXXX-XXXX-XXXX` (дефисы необязательны, добавляются автоматически)
- Пример: `ABCD-1234-EFGH-5678`

После успешной активации:
- Файл лицензии сохраняется в `resources/license.dat`
- Открывается главное окно приложения
- Повторная активация не требуется (если не удалить файл лицензии)

### Основные настройки

| Параметр | Описание |
|----------|----------|
| **Интервал (сек)** | Частота отправки сигналов активности (по умолчанию: 120 сек) |
| **Работать в фоне** | Приложение будет временно переключаться на окно Roblox для отправки сигнала, затем возвращать фокус обратно |
| **Только когда Roblox активен** | Сигналы отправляются только если окно Roblox в фокусе (рекомендуется) |
| **Тип активности** | Выбор способа симуляции активности: |
| &nbsp;&nbsp;• Двигать мышь | Перемещение курсора на 1 пиксель (работает только в активном окне) |
| &nbsp;&nbsp;• Нажимать Shift | Отправка нажатия клавиши Shift |
| &nbsp;&nbsp;• Нажимать Scroll Lock | Отправка нажатия Scroll Lock (самый безопасный вариант для игр) |

### Запуск и остановка

#### Через интерфейс:
1. Нажмите кнопку **[СТАРТ]** для запуска
2. Статус изменится на **"СТАТУС: РАБОТАЕТ"** (зелёный цвет)
3. Нажмите **[СТОП]** для остановки

#### Через горячие клавиши:
- **F10** — быстрый старт/стоп (работает даже если окно свёрнуто в трей)

---

### Авто-реконнект

Функция автоматического переподключения при разрыве соединения в Roblox.

#### Режимы работы:

1. **Авто-поиск по цвету** (по умолчанию)
   - Не требует шаблона
   - Ищет кнопку "Reconnect" по характерным цветам
   - Поддерживаемые цвета: зелёные (#00B06F, #00A86B, ...) и синие (#3C78D8, #4285F4, ...)

2. **По шаблону изображения**
   - Более точное распознавание
   - Требует предварительного захвата шаблона

3. **Через OCR (оптическое распознавание символов)**
   - Распознаёт текст кнопки "Reconnect" / "Подключиться"
   - Использует библиотеку OCR из папки `vendor/`
   - Работает без шаблона, но требует больше ресурсов

#### Как захватить шаблон:

1. Запустите Roblox и дождитесь появления кнопки "Reconnect" (или войдите в режим, где она видна)
2. Наведите курсор точно на **центр** кнопки "Reconnect"
3. Нажмите **F8** или кнопку **[Захватить]** в интерфейсе
4. Шаблон сохранится в `resources/reconnect_template.png`
5. Статус изменится на **"Шаблон кнопки найден"**

#### Включение/выключение:
- Установите галочку **"Авто-реконнект при дисконнекте"**
- Проверка выполняется каждые **5 секунд**
- При обнаружении кнопки реконнекта происходит автоматический клик

## 🔄 Режимы работы

### Обычный режим (без галочки "Работать в фоне")
- Сигналы активности отправляются только когда окно Roblox активно
- Если выбрано "Только когда Roblox активен", в неактивном состоянии действия пропускаются

### Фоновый режим (с галочкой "Работать в фоне")
- Приложение автоматически переключается на окно Roblox
- Отправляет сигнал (Shift или Scroll Lock)
- Возвращает фокус предыдущему окну
- ⚠️ **Не печатайте в момент переключения!**

## 🛠️ Сборка

Для создания исполняемого файла (.exe):

1. Установите **Ahk2Exe** (компилятор AutoHotkey)
2. Откройте `RobloxAFKKeeper.ahk` в редакторе
3. Используйте Ahk2Exe для компиляции
4. Убедитесь, что все папки (`lib/`, `lang/`, `resources/`, `vendor/`) скопированы рядом с .exe файлом

Или используйте скрипт сборки (если доступен):
```bash
tools/build.bat
```

## ❓ Решение проблем

### Приложение не запускается
- Убедитесь, что установлен **AutoHotkey v2.0+**
- Проверьте, что все файлы из репозитория на месте

### Ошибка активации
- Проверьте правильность ввода кода (16 символов, латиница)
- Убедитесь, что код не был использован ранее (если есть ограничения)

### Авто-реконнект не работает
- Убедитесь, что Roblox запущен
- Попробуйте захватить шаблон кнопки заново
- Проверьте, что галочка "Авто-реконнект" включена

### Окно Roblox не находится
- Убедитесь, что Roblox запущен в оконном или полноэкранном режиме
- Проверьте название окна (должно содержать "Roblox")
